# web-front-end-Vue

#### 介绍

**NEVT 科技东奥大数据平台展示页面**
[预览地址](http://asus.work)

#### 软件架构

- 框架：**Vue2**

#### 环境依赖

- node.js
- vue

#### 安装教程

- 下载

  - ```
    git clone https://gitee.com/nevt/web-front-end-vue.git
    ```

- 安装依赖

  - ```
    npm install
    ```

- 启动

  - ```
    npm run dev
    ```



#### 目录结构

```
├─build                 // 打包环境
│      
├─config                // 开发部署配置
│      
├─node_modules			//依赖模块
│      
│  
├─src                   // 项目源文件
│  │  main.js           // 入口文件
│  ├─api                // 请求接口
│  ├─assets             // 组件静态资源
│  │  └─css          	// 样式
|  |  └─fonts			// 字体
|  |  └─img				// 图片
|  |  └─js				// js
|  |  └─json			// json
|  |  └─svg				// svg图片
│  ├─components         // 业务组件
│  ├─view               // 页面组件
│  ├─router             // 路由管理
│              
│  .babelrc             // babel配置
│  .editorconfig        // editor配置
│  .gitignore           // git忽略配置
│  .eslintrc.js         // eslint配置
│  .postcssrc.js        // postcss配置
│  index.html           // 项目首页
│  package.json         // 依赖配置
```
